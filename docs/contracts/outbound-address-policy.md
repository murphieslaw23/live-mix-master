# Outbound address policy — classifier stage

Policy: 2026-10-07-v1. Baseline: b14db2617f97d2c3b0ef129a43455c00cceec457.

Uses node:net isIP and BlockList plus WHATWG URL canonicalization, with no npm dependency or lockfile change. Rejects malformed/scoped IPs, listed IPv4 special-purpose ranges, IPv6 outside 2000::/3 and listed special-purpose IPv6 blocks. IPv4-mapped IPv6 is recognized by a parsed CIDR test and normalized to its underlying IPv4 address before policy checks. This is a deliberately conservative outbound policy: globally reachable special-purpose exceptions can still be denied. Sources: IANA IPv4 and IPv6 Special-Purpose registries reviewed in this workstream (last-updated dates shown 2025-10-09); Node 24 BlockList documentation. Review the versioned tables when assignments change; do not fetch policy data during requests.

validateDnsAnswers rejects empty/oversized sets (>64), invalid addresses, family mismatches and any prohibited answer, then deduplicates/freeze-normalizes approved records. classifyDestination is an internal routing decision: canonical URL handling blocks alternate loopback notation, rejects userinfo/fragments/public HTTP/invalid ports, separates local hostname rules from IP parsing, and treats ordinary fc/fd domain names as DNS destinations. Literal blocked results retain safe reasons only. Approved URLs/addresses are internal and must not be exposed as public diagnostics.
