## Visual direction

SYSTEM CORRUPT / SYCO23 values apply: mechanical totem, ancient visual energy, speaker-wall scale, iron faceplates, stacked modules, drilled fasteners, vents, cabling, worn/oxidized material cues. Use burnt ochre as the key action color. Meter LEDs are functional signal feedback, not decorative neon.

Avoid terminal/console chrome, glossy startup cards, vinyl metaphors, and cyberpunk gradients.
