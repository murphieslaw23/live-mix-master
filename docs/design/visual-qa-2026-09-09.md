# LiveMixMaster visual QA — 2026-09-09

Status: **semantic contract accepted for review; visual baseline partially approved; generated secondary boards rejected as semantic/copy truth**.

This QA separates three different kinds of evidence:

1. repository semantic/interaction truth (`design/*.json`);
2. deterministic visual baseline fixtures;
3. generative layout/art-direction references.

A generated image never overrides the repository token, component-state or operator-journey contracts.

## Contrast verification for the semantic contract

Calculated WCAG contrast ratios against the dark surfaces:

| Pair | Ratio |
| --- | ---: |
| `text/primary` on `surface/base` | 15.76:1 |
| `text/primary` on `surface/rack` | 14.00:1 |
| `text/primary` on `surface/strip` | 12.40:1 |
| `text/secondary` on `surface/base` | 6.05:1 |
| `text/secondary` on `surface/rack` | 5.38:1 |
| `text/secondary` on `surface/strip` | 4.76:1 |
| `accent/copper` on `surface/base` | 3.64:1 |
| `accent/copper` on `surface/rack` | 3.23:1 |
| `accent/copper` on `surface/strip` | 2.86:1 |

Decision: copper is a healthy-state/focus **border, icon and shape accent**, not normal small text on `surface/strip`. Healthy-state copy uses `text/primary` or `text/secondary`. A copper focus ring directly against `surface/strip` needs a primary-text outer edge or placement on rack/base.

## Typography contract

Generative image text is not a typography source of truth. `design/tokens.json` now defines deterministic roles for implementation and golden tests:

- Section Display — Roboto Condensed 700, uppercase.
- UI Label — Roboto Condensed 600, uppercase.
- Body — Inter 400.
- Numeric Telemetry — Roboto Mono 600 with tabular figures.

Production and golden-test environments must bundle the fonts rather than depend on runtime font downloads.

## Generated board QA matrix

The following assets remain valuable for layout composition and feature coverage, but strict visual inspection found enough copy/state defects that they are **not approved as semantic or pixel-exact references**.

| Recovery matrix | REJECT state/pixel truth | Recovery ribbon overlaps card; poor button contrast; no-signal uses healthy-looking color; reconnecting and terminal failed state combined. |
| Tablet field monitor | REJECT copy truth | Duplicated master-channel label; duplicate AUX label. |

These defects are why the hybrid model makes the repository contracts authoritative. The boards may still guide composition, density and visual hierarchy until deterministic Flutter golden fixtures replace them.
